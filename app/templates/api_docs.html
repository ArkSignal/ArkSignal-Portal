API for Builders

The network's public data, for programs: aircraft, receiving stations, weather stations, radiosonde flights and repeaters, as JSON, with a key for each project and fair limits. It is free, for hobby, club, education and community projects.

Sign in (or register), then {% if member_keys %}open My Account > API Keys and make a key for your project{% else %}ask an administrator through Contact for a key for your project (on this site administrators make the keys; you then see yours under My Account > API Keys){% endif %}. It is shown once: copy it.
  2. Send it with every request: Authorization: Bearer YOUR_KEY.
  3. Ask for an endpoint below. Everything is read-only.
curl -H "Authorization: Bearer YOUR_KEY" {{ request.host_url.rstrip("/") }}{{ ex1 }}

print(r.json()["totals"], r.headers["X-RateLimit-Remaining"])
const r = await fetch("{{ request.host_url.rstrip("/") }}{{ ex2 }}", {headers: {Authorization: "Bearer YOUR_KEY"}});
const data = await r.json();

{% endcall %} {% call sec('limits', 'Limits', True) %}

Each key may make {{ per_min }} requests a minute and {{ '{:,}'.format(per_day) }} a day (the day restarts at midnight UTC). Every answer says where you stand:

HeaderMeaning
X-RateLimit-LimitRequests allowed per minute for your key.
X-RateLimit-RemainingRequests left this minute.
X-RateLimit-Day-LimitRequests allowed per day.
X-RateLimit-Day-RemainingRequests left today.
Retry-AfterSeconds to wait, on a 429 answer.

The data changes every few seconds at most, so asking more than about once every five seconds gains nothing. Need more for a real project? Ask through Contact: an administrator can raise one key's limits.

{% endcall %} {% call sec('errors', 'Answers and Errors', False) %}
StatusMeaning
200The data.
401No key, or the key is not valid (it may have been revoked). The body says which: key_required or invalid_key.
403That endpoint is switched off on this site (endpoint_disabled). It is not counted against your limits.
404That part of the network (or the API) is switched off on this site.
429Over a limit: rate_limited (per minute) or daily_limit. Wait for Retry-After.
503The data source is away for a moment. Try again shortly.

Errors are JSON: {"error": "rate_limited", "message": "..."}.

{% endcall %} {% call sec('rules', 'Rules of Use', False) %}
  • Keep your key private and use one per project. A key that leaks is revoked on My Account > API Keys.
  • Be reasonable: stay inside the limits, cache what you can, and do not build something that hammers the network.
  • Say where the data comes from. Radiosonde data is from SondeHub (CC BY-SA 2.0): keep the credit that comes with it. The rest is the network's members' own receivers and stations.
  • Locations are only as precise as each owner chose: the API never reveals more than the site shows. Do not try to work out hidden locations.
  • For hobby, club, education and community use. For a business or a product, ask first.
  • We may change or stop the API; changes to /api/v1/ will add things, not break them, and a new version gets a new address.
