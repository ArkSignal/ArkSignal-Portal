Admin MeshCore

MeshCore is a separate mesh network with its own firmware; it does not use Meshtastic's public server. Its nodes reach this site through observers: programs (meshcoretomqtt) that people run on a repeater or companion and that publish what their radio hears to the broker under meshcore/. This site keeps only the self-announcements (adverts) with a good signature: names, kinds and positions. Chat is encrypted and never read. This page shows what is read from those observers. Reading is set by MQTT Topics to Read under Settings, Mesh Nodes. The counts start again whenever the mesh service restarts.
