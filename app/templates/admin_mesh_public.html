Admin Public Meshtastic Server

What this site sends to Meshtastic's public MQTT server (mqtt.meshtastic.org) and what it reads from it. Sending is the switch Forward to the Public Meshtastic Server; reading is Also Read the Public Meshtastic Server, which pulls in the nodes of Arkansas and the states around it. Both are under Settings, Mesh Nodes. The counts start again whenever the mesh service restarts.

Rules: anything a node sends to the public side of this broker is forwarded, whatever community topic it came in on. A community's private feed is forwarded only when its managers chose Sharing, Public Meshtastic Server. The public server's own rules apply first: default-key channels it lists, allowed message types, positions no more exact than the limit. Packets this service sends itself are never forwarded.
