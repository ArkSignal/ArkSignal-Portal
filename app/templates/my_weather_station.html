Three ways to use it:

  1. Home Assistant (HACS): in HACS open Custom repositories, add {% if ha_repo %}{{ ha_repo }}{% else %}the integration's repository address{% endif %} as an Integration, download ArkSignal Weather, restart Home Assistant, then add the integration under Settings, Devices & services. Paste the upload address above and choose your device. It works with Tempest, Ecowitt, Ambient, Davis and anything else Home Assistant can read.
  2. Tempest without Home Assistant: run the ArkSignal Tempest bridge container on any always-on computer on the same network as your Tempest hub. Save this as compose.yaml and run docker compose up -d: 
    services:
  arksignal-tempest:
    image: ghcr.io/mallison01/arksignal-tempest-bridge:latest
    network_mode: host          # needed to hear the hub's local broadcast
    restart: unless-stopped
    environment:
      ARKSIGNAL_URL: "{{ addr.relay_url }}"
      ARKSIGNAL_ELEVATION_FT: "300"   # your height above sea level, for sea-level pressure
  3. A script: post JSON to the address:
{"temperature": {"value": 71.4, "unit": "°F"}, "humidity": {"value": 52, "unit": "%"}, "pressure": {"value": 29.92, "unit": "inHg"}, "wind_speed": {"value": 6.1, "unit": "mph"}, "wind_gust": {"value": 11, "unit": "mph"}, "wind_direction": {"value": 230, "unit": "°"}, "rain_today": {"value": 0.12, "unit": "in"}}
Each value carries its unit, so send what you have in the units you have. Names: temperature, dew_point, humidity, pressure, wind_speed, wind_gust, wind_direction, rain_today, rain_rate, rain_week, rain_month, rain_year, solar_radiation, uv_index, lightning_count, lightning_distance. The older names with the unit in the name (temp_c, wind_kph, pressure_hpa...) also work.
