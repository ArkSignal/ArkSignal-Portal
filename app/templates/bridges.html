Radio Bridges

Link one of your chats to an amateur radio operator on APRS, or to a node on the Meshtastic mesh. What you write in that chat goes out over the radio network, and what comes back shows up in the chat. Everything here is opt in.

APRS messages go from your own call sign to another operator's call sign through the APRS-IS network (the same way aprs.fi and other web clients send them). Replies addressed to your call sign from that operator appear in the chat.

  • Your call sign comes from your Profile: {% if call %}{{ call }}{% elif profile_call %}{{ profile_call }} is not a call sign this bridge can use{% else %}none yet{% endif %}.
  • Only what you write in the linked chat is sent, under your call sign. Other people's messages in the chat are never sent, because only a licensed operator may transmit under a call sign.
  • APRS messages are plain ASCII text of at most {{ max_text }} characters, never encrypted, coded or hidden. A message that does not fit is not sent, and the chat tells you so.
  • You can send about {{ per_hour }} an hour. Each message sent and received is in the site's audit log (who and when, never the words).

A chat can be linked to a mesh node (for example !a1b2c3d4): what you write is queued for the mesh gateway to send to that node as a text message, and text the gateway hears from that node is added to the chat. The mesh messages are text only and as plain as the mesh channel they use. The gateway that talks to the mesh is still being built, so a message may wait in the queue.
