{# The filled-in commands for one login. Needs: host, port, topic, user, pw. #}

Meshtastic: command line

meshtastic --set mqtt.enabled true \
  --set mqtt.address {{ host }} \
  --set mqtt.username {{ user }} --set mqtt.password {{ pw }} \
  --set mqtt.tls_enabled true --set mqtt.root {{ topic }} \
  --set mqtt.map_reporting_enabled true

In the app or web client the same values go under Radio Config → Module Config → MQTT: Address, Username, Password, TLS on, Root topic, Map Reporting on.

MeshCore: meshcoretomqtt (config.d/99-user.toml)

[[broker]]
name = "arksignal"
enabled = true
server = "{{ host }}"
port = {{ port }}
tls.enabled = true
auth.method = "password"
auth.username = "{{ user }}"
auth.password = "{{ pw }}"
