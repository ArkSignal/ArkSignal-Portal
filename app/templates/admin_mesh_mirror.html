Read Another Site

On the site that should mirror (the test site, say): paste a mirror login made on the other site. This site then also reads that site's public mesh feed, live, as if the nodes had been heard here. It is the same as filling in Settings, Mesh Nodes, Public Server, and replaces what is there (by default mqtt.meshtastic.org). Keep the communities' forwarding off on a mirror site, so nothing is sent back (a mirror login cannot publish, so it would only fail).
