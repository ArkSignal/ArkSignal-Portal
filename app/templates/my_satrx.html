The ArkSignal uploader (see How to Feed) sends new pictures from a folder by itself. Or your decoding software writes each finished picture as a PNG or JPEG file and you send it to the receiver's upload address (shown on its card above) with any program that can post a file. With curl:

curl -F image=@meteor_pass.png -F satellite="METEOR-M2 3" -F product="MSA false color" -F captured=2026-10-17T05:51:14Z UPLOAD_ADDRESS

Only image is needed. satellite and product are the words shown under the picture, captured is when the satellite passed (a time like the one above, in UTC; the time it arrives is used when left out) and note is a short line of your own.

  • SatDump (Meteor-M LRPT, GOES HRIT, and others): run it with its output folder set, and add a small script that sends each new image file in that folder, or use its post-processing hook if your version has one.
  • goestools (GOES HRIT and LRIT): the same idea; point a script at the folder where it saves the full-disk and sector images.
  • A picture must be a PNG, JPEG or WebP file. Anything else is refused with a plain message.

The Satellite Passes page shows when each satellite is overhead, so a script can run at the right times. Pictures you send are shown to everyone when the receiver is public: only send what you are happy to share. You can delete any of them, or the whole receiver, at any time.
