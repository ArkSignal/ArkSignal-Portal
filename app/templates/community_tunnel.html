Set It Up on the Device

The device that runs the tunnel must be able to reach the gateway node: either the gateway itself (a computer or small box with WiFi or ethernet and the MQTT settings below) or a router or small box on the gateway's network.

Phone or tablet (Android, iPhone)
  1. Install the WireGuard app from the Play Store or the App Store.
  2. Tap the plus, then Scan from QR code, and scan the code above. Name it and allow the VPN request.
  3. Switch it on. Only the tunnel address goes through it; the rest of the phone's traffic does not.

A phone is useful for checking the tunnel or for a node that connects through the phone's network. A node sends MQTT itself over WiFi or ethernet; the Meshtastic app does not carry the private feed.

Linux (Debian, Ubuntu, Raspberry Pi OS, and similar) 
sudo apt install wireguard
sudo nano /etc/wireguard/arksignal.conf      # paste the text above, save
sudo chmod 600 /etc/wireguard/arksignal.conf
sudo wg-quick up arksignal                   # start it now
sudo systemctl enable wg-quick@arksignal     # start it at every boot
sudo wg show                                 # "latest handshake" appears within seconds
nc -vz {{ address }} 1884                    # should say open (the tunnel does not answer ping)

On Fedora and Red Hat use dnf install wireguard-tools; on Alpine apk add wireguard-tools. To use a different name than arksignal, change the file name and the two commands to match.

Windows and Mac
  1. Install WireGuard from wireguard.com/install (or the Mac App Store).
  2. Download the .conf file above, then in WireGuard choose Import tunnel(s) from file (Windows) or Import Tunnel(s) from File (Mac), and activate it.
A router or firewall (OpenWrt, pfSense, OPNsense, MikroTik, and similar) in front of the gateway node

Make a WireGuard client interface with the values from the configuration: the Interface private key and address, and one Peer with the server's public key, the endpoint, allowed IPs {{ address }}/32 and a keepalive of 25 seconds. Then:

  • Add a route for {{ address }}/32 through that interface (do not route anything else; allowed IPs must stay that single address).
  • Translate (masquerade) the gateway node's traffic going into the tunnel, because the server knows only this one tunnel address, not your LAN.
  • The gateway node keeps its normal network. Its MQTT address is {{ address }}, port 1884.
Check that it works, and if it does not
  • Broker Logins shows the peer as connected just now within a minute or so of switching the tunnel on. Never connected means no handshake reached the server.
  • No handshake: the endpoint ({{ endpoint }}) must be reachable from where the device is, and UDP 51820 must be forwarded to the server. A device behind a strict firewall may need the keepalive kept at 25.
  • Handshake but no data: allowed IPs must include {{ address }}/32, and a router in front needs the translation above.
  • The server's clock and the device's clock should be within a few minutes of each other.

Gateway MQTT Settings

On the gateway node, in the Meshtastic app under Module Configuration, MQTT (the node reaches this address only while the tunnel is up):

MQTT enabledOn
Address{{ address }}:1884
Username and password{% if login %}The login {{ login }} and its password (open the login in Broker Logins to see it). This peer can use that login and no other, and that login works only through this peer's tunnel.{% else %}The Private feed login this peer is bound to (Broker Logins).{% endif %}
Root topic{{ root }}
Encryption enabledOff, so the gateway sends decoded packets (the private map cannot read what stays encrypted)
TLS enabledOff (the tunnel is already encrypted)
Uplink enabledOn, for each channel the gateway should send

Use the address as the numbers {{ address }}, not a name: the firmware decides that a broker is private from its address. A node's own gateway is always uplinked. Packets of other nodes are sent whatever their OK to MQTT setting says, because the address is private; only what the public server would have accepted goes on to the public maps.
