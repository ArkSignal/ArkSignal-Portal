Email (SMTP)
Use smtp.gmail.com for a Gmail account (with an App Password, not the account password), or any other SMTP relay.
Usually 587 for STARTTLS, 465 for SSL/TLS, or 25 for an unencrypted relay. It must match Connection Security below.
STARTTLS and SSL/TLS both encrypt the message and the login. None sends everything, including the password, as plain text; use it only for a trusted relay on your own network.
Usually the full email address of the mailbox, or the username for a transactional email service. Leave blank if the server needs no login.
For Gmail, an App Password generated in Google Account settings (2-Step Verification must be on). It is stored encrypted and never shown again.
