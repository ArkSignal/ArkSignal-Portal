Admin Matrix Chat

The chat server (Matrix) that members reach with the Element app. Members sign in with their ArkSignal account: there are no separate Matrix passwords, and the site's two-factor sign-in and passkeys still apply.
{% include "partials/_admin_subnav.html" %} {% include "partials/_admin_matrix.html" %} {% call sec('setup', 'Setting It Up (Once)', False) %}
  1. DNS: a record for {{ public_url.split('//')[-1] }} and one for {{ element_url.split('//')[-1] }}, pointing where the site's other names point.
  2. Nginx Proxy Manager, the Matrix address: a proxy host for {{ public_url.split('//')[-1] }} that forwards to scheme http, host matrix, port 8008, with Websockets Support and Block Common Exploits on, a Let's Encrypt certificate with Force SSL and HTTP/2, and this in its Advanced tab: 
    client_max_body_size 50M;
proxy_read_timeout 600s;
proxy_send_timeout 600s;
proxy_buffering off;
  3. Nginx Proxy Manager, the chat page: a proxy host for {{ element_url.split('//')[-1] }} that forwards to scheme http, host element, port 8080, with a certificate and Force SSL (Websockets Support is not needed). Nothing else: the site's own page shows it inside the Chat page.
  4. The site's own address: the Matrix apps look for {{ server_name }}/.well-known/matrix/client to find the server; the site answers that by itself once Matrix Chat is on. The router and firewall need nothing new (443 is already open for the proxy).
  5. In Settings > Matrix Chat check the server name and the two addresses (the sign-in return address is worked out from the Matrix address by itself: {{ public_url }}/_synapse/client/oidc/callback), then set Matrix Chat to On.
  6. Press Apply above. The site makes a sign-in secret, gives it to the Matrix service together with the settings, and Synapse starts. Then press Sync Now to make the standing rooms.

The server name cannot be changed after people have used it, because it is part of every Matrix address. Moving members' old chats and messages over is not done: they stay where they are, closed, in the site's database.
