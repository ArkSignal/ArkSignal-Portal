Import Hospital Data

Load a CSV file with the columns name, ccn, city, state, level, designated, lat, lon, services, source. Only name is required, plus at least one of level (I to V or 1 to 5; blank or 0 means not designated) and services (words such as stroke, neuro, cardiac, OB, NICU, pediatric, burn, ortho, oncology, surgery, ICU, CT, vascular, IR, facial, eye, separated by semicolons; services in the file are added to the ones already on record). One file may carry levels, services or both, so the same box takes the state trauma list and the hospital capability list. A row with a ccn (the CMS certification number, the Facility ID in the CMS list) is matched exactly; otherwise by position and name. A row that matches nothing is added. Download an example file.
