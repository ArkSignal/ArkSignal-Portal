# Contributing

Thanks for helping. This repository is a **mirror**: the project is developed in a private repository and each release is published here as one commit.

- **Bugs and ideas:** open an issue (use the templates). Security problems go through the private report described in [SECURITY.md](SECURITY.md).
- **Code:** pull requests are welcome, but they cannot be merged here. A maintainer applies an accepted pull request to the private repository by hand
  (keeping your authorship and sign-off), and it appears here with the next release. Please keep a change small and say how you tested it.
- **Sign-off:** every commit needs a `Signed-off-by: Your Name <you@example.com>` line (`git commit -s`), which states the
  [Developer Certificate of Origin](https://developercertificate.org/): you wrote the change or have the right to submit it under the project's license,
  the GNU Affero General Public License v3.0.
- **Style:** match the surrounding code; US spelling in text shown to users.
